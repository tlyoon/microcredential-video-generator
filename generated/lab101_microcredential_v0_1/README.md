# Lab 101 Microcredential Draft Output v0.1

This folder contains the first draft slide-stack and narration-script output for the Physics Laboratory 101 microcredential video set.

## Status

Draft for instructor review. This was generated in the current ChatGPT workflow for repository staging; it is not a live `microvid all` Gemini API run. Review the technical content, equations, units, and narration before using the scripts for final TTS/video production.

## Files

- `course_plan.yaml` — nine-video course map.
- `slide_stack_and_scripts.md` — complete slide-by-slide stack with narration script for each slide.
- `LOCAL_VIDEO_BUILD_NOTES.md` — suggested way to turn the assets into video files on a local PC.

## Intended local use

After pulling the repository, use `slide_stack_and_scripts.md` as the source for building/adjusting PowerPoint slide decks and for TTS narration. The current package can still be used locally for Gemini/Chirp/FFmpeg production once the source manual and credentials are available.
